Q&A

Common questions

Use expandable answers so the page stays calm while still covering contributor details.

What resources can I submit?

You can submit datasets, models, workflows, OERs, benchmarks, tools, and construction data examples. The best submissions include a stable source link, clear ownership, a license or access condition, and enough metadata for others to evaluate reuse.

Do I need to host files on OpenConstruction?

No. OpenConstruction primarily indexes public metadata and points users to original repositories, project pages, DOIs, papers, or code. Use a stable repository or project page whenever possible.

What metadata should I prepare before submitting a dataset?

Prepare title, source URL, authors or contributors, year, license, data modality, tasks, classes or labels, collection context, repository or DOI, paper link if available, and notes about privacy, access limits, or known quality issues.

What if my construction dataset contains sensitive site information?

Document the sensitivity clearly. Review faces, license plates, site locations, critical infrastructure, worker privacy, contract restrictions, and consent conditions before sharing. If public release is not appropriate, describe access limits or provide metadata only.

How do I report a broken link or incorrect metadata?

Use the correction report workflow and explain what is wrong, what the corrected value should be, and any source that supports the change. This keeps issue reporting useful without making it the main tutorial story.

Do I need an account?

You can browse and watch learning content without an account. Sign in when you want to submit resources, save progress, take assessments, earn certificates, bookmark resources, or report corrections through the workspace.

How long does review take?

Review time depends on completeness and maintainer availability. Submissions with stable links, clear licensing, strong metadata, and concise reuse notes are easier to approve quickly.
