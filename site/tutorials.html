Q&A

Submission and Review Guidance

What resources can I submit?

You can submit datasets, models, workflows, OERs, benchmarks, tools, and AEC data examples. The best submissions include a stable source link, clear ownership, a license or access condition, and enough metadata for others to evaluate reuse.

Do I need to host files on OpenConstruction?

No. OpenConstruction primarily indexes public metadata and points users to original repositories, project pages, DOIs, papers, or code. Use a stable repository or project page whenever possible.

What metadata should I prepare before submitting a resource?

Prepare the resource title, a public source link, basic contributor or organization information, and any known license or access notes. Add a short description so reviewers can understand what the resource is and how it may be reused.

What if my dataset contains sensitive site information?

Document the sensitivity clearly. Review faces, license plates, site locations, critical infrastructure, worker privacy, contract restrictions, and consent conditions before sharing. If public release is not appropriate, describe access limits or provide metadata only.

How do I report a broken link or incorrect metadata?

Use the correction report workflow and explain what is wrong, what the corrected value should be, and any source that supports the change.

Do I need an account?

You can browse content without an account. Sign in when you want to submit resources, bookmark resources, or report corrections through the workspace.

How long does review take?

Review time depends on completeness and maintainer availability. Submissions with stable links, clear licensing, strong metadata, and concise reuse notes are easier to approve quickly.
