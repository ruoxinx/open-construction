MCP Beta

Assistant Tool Access

The MCP server exposes OpenConstruction catalog capabilities to compatible assistant clients through a small set of structured tools.

search_resources

Search public OpenConstruction catalog resources.

get_resource

Fetch one resource by type and id.

compare_resources

Compare catalog entries for a task or reuse goal.

run_dataset_discovery

Run the Dataset Discovery skill with structured inputs and ranked results.

get_catalog_stats

Summarize the loaded catalog snapshot.

ask_openconstruction

Answer a user question using catalog evidence.

list_skills

List skill definitions from the repo-owned registry.

get_skill

Fetch one skill definition by id.

Install Local Server

Clone the repo and install the package in editable mode.

git clone https://github.com/open-construction/open-construction-agent-api.git
cd open-construction-agent-api
python -m pip install -e .

Connect Assistant Client

Add the server command to an MCP-compatible client.

{
  "mcpServers": {
    "openconstruction": {
      "command": "python",
      "args": ["-m", "openconstruction_mcp.server"]
    }
  }
}
